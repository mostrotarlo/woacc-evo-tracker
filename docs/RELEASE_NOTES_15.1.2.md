# WOACC EVO & ACC Tracker 15.1.2

Windows x64 application for Assetto Corsa EVO and Assetto Corsa Competizione.

Includes the desktop application, Windows service engine and complete user
manual in Italian, English, French and Spanish.

Download **WOACC_Tracker_v15.1.2_Windows_x64.zip** and extract the entire archive
before starting **WOACC Tracker.exe**. Keep both `_internal` directories and
the complete **WOACC Tracker Engine** folder. Python is not required.

Existing configuration remains in `%APPDATA%\WOACC_Tracker\config.json`.
Back up configuration and database and stop the previous tracker or service
before upgrading. Do not run two instances against the same database.

Demo: https://woacc.zapto.org/tracker/
